# Java EE API reference pack

These unmodified API binaries, source archives and POMs are obtained from Maven Central at the URLs and SHA-256 hashes recorded in manifest.json:

- javax.servlet:javax.servlet-api:4.0.1
- javax.servlet.jsp:javax.servlet.jsp-api:2.3.3

Both original POMs declare CDDL + GPLv2 with the Classpath Exception. The full license text in LICENSE-CDDL-GPL-CLASSPATH.txt is preserved from META-INF/LICENSE.txt in the Servlet 4.0.1 artifact. The JSP archives do not contain a separate root LICENSE/NOTICE entry; their original POM and all source copyright/license headers are preserved alongside the artifacts. The original license reference is https://oss.oracle.com/licenses/CDDL+GPL-1.1 .

This is an analysis reference pack. It does not replace the analyzed project's dependency versions or the analyzer's own Servlet/Jasper runtime. Selection is disabled by default and exact project coordinates are required for fallback.
